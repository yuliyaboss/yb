# I.8 · исходники

Финальные исходники системы I.8 (бывший «Протокол 108»): рабочая тетрадь на 108 дней + Карта I.8.

## Структура
- `src/` — скрипты сборки
  - `i8.js` + `i8.css` — **рабочая тетрадь I.8** (163 стр.) и отдельный **блок дней 1–108** (133 стр.). Все тексты, цели и сферы — в начале `i8.js`
  - `map.py` — Карта 108 (печать 2634×4110 + заставка на телефон 1290×2796), единый фильтр `grade()`
  - `tiles.py` — плитки 900px для вкладыша
  - `insert.js` — PDF-вкладыш A4: карта, «Кто я сегодня», «Правила обмена», «Чакры и эгрегоры», 5 сфер
  - `cover2.py` — обложка VOGUE (North Star) → `assets/star collage.jpg`
  - `ig.js` — профиль Instagram 1 mln → `assets/zen grid.png`
  - `n.js` — уведомление Revolut +108 000 zł → `assets/Доход 108 000 zł.jpg`
  - `lueur_ad.py` — карточки LUEUR
  - `cut.py` — нарезка ячеек из старых обоев → `assets/cells/`
  - `cover.py`, `star.py` — старые версии обложки (архив)
- `assets/photos/` — оригиналы фото (загрузки)
- `assets/fonts/` — шрифты
- `assets/cells/` — ячейки карты
- `assets/*.jpg|png` — готовые составные кадры (обложка, профиль, доход, фонд, LUEUR)
- `output/` — финальные файлы
- `reference/` — старая версия «Протокол 108» (PDF, только образец)

## Пересборка
```
./build.sh
```
Нужны python3 + Pillow + numpy, node + playwright (chromium). Результат будет в `output/`.
